# auto_watering_system

The main purpose of this project is to automate plant watering while allowing the user to select different cultivation modes for plants that grow in Puerto Rico, such as beans, peppers, and tomatoes. Each crop type will have different watering parameters which will be chosen with a state machine to adjust the quantity or duration of water delivery according to the selected mode. This creates a more customized and efficient irrigation process instead of applying the same watering pattern to every plant

It also includes a manual mode that allows the user to set a custom timer for when watering begins. The watering can be stopped with button interrupt.
